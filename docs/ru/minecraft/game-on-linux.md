# Как скачать и запустить Arsland Launcher на Linux (включая Steam Deck)

> **Автор гайда:** [SADOVNIK](https://discord.com/users/863335400868675604)

Установка лаунчера Arsland на любой дистрибутив Linux (а также на Steam Deck в режиме рабочего стола Desktop Mode) состоит из двух этапов: скачивания файла формата **AppImage** и выдачи ему прав на исполнение.

---

## Этап 1. Скачивание лаунчера

1. Перейдите на официальный сайт **Arsland**.
2. В левой нижней части экрана нажмите на иконку пингвина **Tux** (маскот Linux).
3. Нажмите кнопку **«Играть»** — браузер начнет загрузку файла `ArslandLauncher-0.0.3-alpha.AppImage`.

---

## Этап 2. Сделать файл исполняемым и запустить

Выберите один из двух удобных способов:

### Способ 1. Через графический интерфейс (GUI)

1. Откройте файловый менеджер (Dolphin на Steam Deck / KDE) и перейдите в папку с загруженным файлом (обычно это `~/Загрузки` или `~/Downloads`).
2. Нажмите правой кнопкой мыши (или используйте правый трекпад / кнопку L2/R2 на Steam Deck) по файлу `ArslandLauncher-0.0.3-alpha.AppImage` и выберите пункт **«Свойства»** (последний в списке).
3. В окне свойств найдите переключатель **«Исполняемый как приложение»** (в разделе *Разрешения*) и переведите его в положение **«Включено»**.
4. Запустите лаунчер двойным кликом по файлу.

---

### Способ 2. Через терминал (CLI)

1. Откройте терминал (Konsole) и перейдите в каталог с файлом:
   ```bash
   cd ~/Downloads
   ```
   *(если система на русском языке, используйте `cd ~/Загрузки`)*

2. Сделайте файл исполняемым с помощью команды `chmod +x`:
   ```bash
   chmod +x ArslandLauncher-0.0.3-alpha.AppImage
   ```
   *Совет: вы можете ввести первые буквы названия файла (`Ars...`) и нажать клавишу **Tab**, чтобы терминал автоматически доставил полное имя.*

3. Запустите лаунчер:
   ```bash
   ./ArslandLauncher-0.0.3-alpha.AppImage
   ```
